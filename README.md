# argosbx-new

基于甬哥原版深度优化的 Argosbx 一键无交互脚本，支持 ENC、Argo 隧道智能切换、多优选IP、哪吒探针及 Gist 订阅同步

**当前版本**: V26.05.12
**技术栈**: Shell, HTML, GitHub Gist API, Nezha Agent

---

## 🌟 核心特色

- 支持 4 种 VLESS 协议的独立 ENC 加密
- Argo 隧道智能协议选择 (UDP OK -> QUIC, UDP Restricted -> HTTP2)
- 多优选IP/域名支持 (用 ; 分隔，生成多个节点)
- 哪吒探针 (Nezha Agent) 自动化安装与配置
- GitHub Gist 自动推送，输出 Raw 格式订阅链接
- 国家代码自动检测，节点 Tag 规范化
- 容器环境兼容性自愈
- POSIX Shell 兼容 (dash/ash 环境可用)
